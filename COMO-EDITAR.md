# Cómo editar tu portfolio tú solo (súper fácil)

No necesitas saber programar. Tienes un panel de administración propio.

## 1. Entra al panel
Ve a la dirección de tu web y añade `/admin` al final:

```
https://tu-web.com/admin
```

Te pedirá la contraseña privada configurada en el alojamiento. No está guardada
en GitHub. Cámbiala cuando quieras en la pestaña **Settings** (ver abajo).

## 2. Qué puedes editar (pestañas de la izquierda)

| Pestaña | Qué cambia |
|---|---|
| **Songs** | Tus Music Projects. Añadir / editar / borrar canciones, subir la portada, y pegar el enlace de Spotify y de YouTube de cada una. |
| **Hero** | El texto grande de la portada y la imagen de fondo. |
| **About** | El texto de "Crafting sound with intention" y las etiquetas de skills. |
| **Experience** | Tu experiencia (Studio Assistant, etc.). |
| **Certifications** | Tus certificados (Pro Tools, MIDAS, Ableton...). |
| **EPR** | El texto de la sección de EPR Standard. |
| **Socials** | Tus enlaces a Instagram, YouTube, TikTok, Spotify. |
| **Settings** | Cambiar la contraseña del panel. |

## 3. Cómo añadir una canción nueva
1. Pestaña **Songs** → botón **+ Add song**.
2. Rellena: título, descripción, roles (Producer, Mixing Engineer, etc.).
3. **Portada:** sube una imagen (se guarda automáticamente).
4. **Spotify:** pega solo el ID del track. Ejemplo: si el enlace es
   `https://open.spotify.com/track/`**`4cOdK2wGLETKBW3PvgPWqT`**, el ID es lo que va en negrita.
5. **YouTube:** pega solo el ID del vídeo. Ejemplo: en
   `https://youtube.com/watch?v=`**`dQw4w9WgXcQ`**, el ID es lo de después del `v=`.
6. **Guarda.** Aparece en la web al instante. Al pulsar la tarjeta se abre con los reproductores de Spotify y YouTube.

## 4. Importante
- Todo se guarda en una base de datos, así que los cambios **no se pierden** aunque actualices la web.
- Si te equivocas, simplemente vuelve a editar y guardar. No rompes nada.
- Si olvidas la contraseña, puedes restablecer `ADMIN_PASSWORD` de forma privada
  en el panel del alojamiento.
